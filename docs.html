Manual Técnico & Guía de Referencia

SVG Motion Studio Pro v4.0 es una suite especializada en la manipulación y animación declarativa de gráficos vectoriales SVG utilizando exclusivamente estándares web nativos (CSS3 y Vanilla JS).

Arquitectura Cero Dependencias

A diferencia de bibliotecas pesadas como GSAP, Lottie o Anime.js que demandan dependencias de runtime adicionales y empaquetadores complejos, SVG Motion Studio Pro compila las animaciones en bloques <style> embebidos directamente en el árbol XML del SVG.

  • Portabilidad Absoluta: El archivo .svg generado contiene sus propios @keyframes y se anima de forma completamente autónoma en cualquier visor web, navegador o etiqueta <img>.
  • Transform-Box Fill-Box: Implementa la especificación SVG2 transform-box: fill-box; transform-origin: center center;, garantizando que rotaciones y escalas calculen su eje geométrico sobre el vector real sin deformaciones.
  • Rendimiento por GPU: Los motores de renderizado aceleran por hardware las propiedades transform y opacity, eliminando cálculos pesados de layout y repaint en el hilo principal de JavaScript.

2. Inicio Rápido en 30 Segundos

Aprende el flujo de trabajo esencial para animar cualquier ilustración o logotipo vectorial:

  1. Cargar el Vector: Arrastra tu archivo .svg a la zona de carga, selecciónalo mediante el explorador local o pega directamente el código XML <svg>...</svg> en el panel izquierdo.
  2. Seleccionar Capa Objetivo: En el dropdown Capa Objetivo, elige si deseas animar el SVG global, aplicar una cascada multicapa (Stagger) o aislar una capa específica (g, path, polygon).
  3. Elegir Efecto & Curva: Selecciona uno de los 13 efectos nativos (respiración, latido, dibujo stroke, tada, etc.) y ajusta la velocidad y curva de aceleración (Easing Engine).
  4. Seleccionar Disparador: Elige entre bucle continuo (Loop), activación interactiva con el cursor (Hover), entrada fija (Once) o revelado al hacer scroll (Scroll Reveal).
  5. Exportar: Elige tu formato preferido (SVG Standalone, Sprite Symbol, React, Vue, Svelte, Web Component, Astro o CSS) y pulsa Descargar Archivo o Copiar al Portapapeles.

3. Modos de Disparo (Animation Triggers)

Controla cómo y cuándo se reproduce la coreografía de movimiento:

Disparador Regla CSS Generada Caso de Uso Recomendado
🔄 Loop (Infinito) animation: ... infinite; Spinners de carga, fondos sutiles, microanimaciones de marca.
👆 Hover (:hover) svg:hover .target { animation: ... } Iconos de interfaz, botones de acción (CTA), tarjetas interactivas.
▶️ Once (Entrada única) animation: ... 1 normal forwards; Animaciones de bienvenida en hero sections, alertas visuales.
📜 Scroll Reveal .is-visible .target { animation: ... } Ilustraciones en landing pages que se activan al llegar con scroll.

Implementación de Scroll Reveal con IntersectionObserver

Al exportar en modo Scroll Reveal, se inyecta un script optimizado de solo 5 líneas que monitorea el elemento con rendimiento óptimo:

const observer = new IntersectionObserver((entries) => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add('is-visible');
      observer.unobserve(e.target);
    }
  });
}, { threshold: 0.2 });

document.querySelectorAll('.animated-svg-reveal').forEach(el => observer.observe(el));

4. Capas & Secuenciación en Cascada (Stagger Engine)

El motor Stagger Engine permite orquestar composiciones complejas donde múltiples elementos se mueven de manera coordinada pero secuencial.

¿Cómo funciona el cálculo de Stagger?

Al seleccionar 🌊 Cascada Multicapa (Stagger / Sequential), el estudio analiza el orden jerárquico del DOM y asigna a cada nodo un índice relativo. Se expone un control deslizante de desfase (de 20ms a 400ms).

En el código exportado, la sincronización se calcula dinámicamente mediante variables nativas CSS: 

.stagger-target {
  transform-box: fill-box;
  transform-origin: center center;
  animation: svgMotion 2.5s ease-in-out infinite;
  animation-delay: calc(var(--stagger-idx, 0) * 80ms);
}

Esto permite modificar el tiempo global o el retardo sin tener que reescribir docenas de reglas estáticas en la hoja de estilos.

5. Trazado Progresivo de Líneas (Stroke Draw)

La animación ✍️ Dibujo / Stroke Draw replica el efecto clásico de dibujo a mano alzada vector por vector.

Cálculo de Perímetro con getTotalLength()

El motor consulta en tiempo real la longitud geométrica exacta de los trazos del SVG. Si un elemento es un polígono o un path cerrado que originalmente carece de contorno (como ocurre comúnmente en isotipos vectoriales), el estudio le asigna automáticamente un stroke visible con su color de relleno para que el efecto sea apreciable de inmediato. 

@keyframes svgMotion {
  0% { stroke-dasharray: 1200; stroke-dashoffset: 1200; fill-opacity: 0; }
  60% { stroke-dashoffset: 0; fill-opacity: 0; }
  85%, 100% { stroke-dashoffset: 0; fill-opacity: 1; }
}

6. Paleta Reactiva & Variables CSS

El módulo Paleta de Colores del SVG escanea todos los atributos fill, stroke y estilos en línea de la ilustración activa.

Tokenización de Color

Al marcar la opción Convertir a Variables CSS, el exportador extrae todos los colores hexadecimales y los reubica en un bloque :root dentro de la etiqueta <style> del SVG: 

:root {
  --color-token-1: #38bdf8;
  --color-token-2: #6366f1;
}

polygon#facet-top { fill: var(--color-token-1, #38bdf8); }
polygon#facet-left { fill: var(--color-token-2, #6366f1); }

De este modo, puedes redefinir la paleta desde tu propia web o cambiar el tema oscuro/claro alterando únicamente las variables CSS superiores.

7. Limpiador & Optimizador SVG

Los archivos SVG generados por herramientas como Illustrator, Inkscape o Figma suelen acumular metadatos propietarios y decimales redundantes que aumentan el peso innecesariamente.

Procesamiento en el Cliente (Sin Servidor)

  • Elimina etiquetas vacías <defs>, comentarios XML y bloques <metadata>.
  • Purga atributos de programas de edición como inkscape:*, sodipodi:* y adobe:*.
  • Redondea las coordenadas de paths en el atributo d a 2 decimales para aligerar la cadena sin alterar la fidelidad visual.
  • Normaliza el atributo viewBox para evitar recortes accidentales al escalar el lienzo.

Web Component Nativo (HTML puro / WordPress)

Compatible con cualquier CMS o sitio web sin necesidad de compilador:

<!-- 1. Cargar el script del componente -->
<script src="./animated-svg-icon.js" defer></script>

<!-- 2. Utilizar en cualquier parte del DOM -->

Sprite Symbol (<symbol> con <use>)

La solución más eficiente para sistemas de iconos donde la misma figura se repite en múltiples vistas:

<!-- Coloca este bloque una sola vez al inicio de tu body -->
<svg xmlns="http://www.w3.org/2000/svg" style="display: none;">
  <symbol id="icono-animado" viewBox="0 0 250 220">
    <style>
      @keyframes svgMotion { ... }
      .animated-target { animation: svgMotion 2.5s ease-in-out infinite; }
    </style>
    <g class="animated-target">...</g>
  </symbol>
</svg>

<!-- Invócalo tantas veces como quieras sin duplicar los vectores -->
<svg width="48" height="48"><use href="#icono-animado"/></svg>
<svg width="64" height="64"><use href="#icono-animado"/></svg>

9. Creación de Keyframes CSS Personalizados

Puedes expandir el catálogo definiendo tus propias reglas @keyframes en el editor lateral:

Estructura recomendada

Al redactar un keyframe, asigna el nombre customAnim. El motor lo mapeará automáticamente tanto en el lienzo como en la exportación: 

@keyframes customAnim {
  0% {
    transform: scale(1) rotate(0deg);
  }
  30% {
    transform: scale(1.18) rotate(-6deg);
    filter: drop-shadow(0 0 15px rgba(56, 189, 248, 0.6));
  }
  60% {
    transform: scale(0.95) rotate(4deg);
  }
  100% {
    transform: scale(1) rotate(0deg);
  }
}

Tus animaciones se guardan de forma persistente en localStorage y puedes compartirlas o respaldarlas en un archivo .json con los botones Exportar JSON e Importar JSON.
